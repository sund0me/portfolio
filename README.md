# AI Automation Engineer · Portfolio

Практические примеры автоматизации, RAG и разработки интерфейсов.
Репозиторий показывает технические подходы через самостоятельные демонстрации,
без раскрытия работодателей, заказчиков и рабочей инфраструктуры.

## Проекты

| Проект | Задача и решение | Технологии |
| --- | --- | --- |
| [RAG pipeline](projects/rag-pipeline) | Подготовка Markdown-документов для векторного поиска: чанки, восстановление метаданных после embedding, группировка и стабильные ID точек | JavaScript, n8n, Qdrant |
| [Support toolkit](projects/support-toolkit) | Независимые строительные блоки API: валидация входных данных и хеширование паролей | TypeScript, Node.js, scrypt |
| [Portfolio web](projects/portfolio-web) | Двуязычный интерфейс с интерактивными навыками, WebGL и поддержкой reduced motion | Next.js, React, TypeScript, Three.js, GSAP |

## Запуск

Для тестов и RAG-демонстрации нужен Node.js 24 или новее. Зависимости устанавливать не требуется.

```sh
npm test
npm run demo:rag
```

Инструкции запуска интерфейса находятся в его README.

## Что демонстрирует репозиторий

- Подготовку данных для RAG и интеграцию Code nodes в n8n.
- Обработку некорректных входных данных и проверку граничных случаев.
- Хранение паролей в виде хешей с отдельной случайной солью.
- Создание адаптивных интерфейсов и интерактивных компонентов.

Это сокращённые демонстрационные версии, а не исходные production-системы.
Документы, ID и векторы в примерах вымышлены. Демонстрационные векторы не являются
семантическими embeddings. Код не обращается к рабочим сервисам.
Политика подготовки публичных материалов: [PUBLICATION.md](docs/PUBLICATION.md).
