# WebChat · pet-project

Локальная демонстрация браузерного чата на React и TypeScript, подготовленная
на основе компонентов и утилит личного проекта WebChat.

Включены оригинальные модули группировки каналов, форматирования вложений,
настройки клавиатурной отправки и компонент индикатора набора. Отдельная
демонстрационная оболочка связывает их без подключения к исходному серверу.

## Возможности демонстрации

- Переключение каналов с независимыми списками сообщений.
- Отправка сообщений по Enter или Ctrl / Cmd + Enter.
- Сохранение предпочтения клавиатурного режима локально в браузере.
- Демонстрационный индикатор набора.
- Адаптивный интерфейс и тесты компонентов.

```sh
cd pet-project
npm ci
npm run dev
```

Проверки:

```sh
npm test
npm run lint
npm run build
```

Нужен Node.js 24+. Сообщения существуют только в памяти вкладки и удаляются при
обновлении страницы. Участники, каналы и исходные сообщения вымышлены.
Отправка работает внутри локальной демонстрации; обмен между пользователями
и соединение WebSocket не реализованы в этой публичной версии.

Не включены авторизация, серверные интеграции, голосовые сервисы, push-ключи,
инфраструктура развёртывания, исходные переменные окружения, отчёты аудита,
реальные аккаунты, диалоги и бинарные материалы. История исходного проекта
не переносилась. Это ограниченная публичная демонстрация, а не полная серверная система.
