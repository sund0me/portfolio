# Веб-чат

Онлайн-чат в стиле Discord с интерфейсом military-tech. Поддерживает персонализацию, темы оформления, медиавложения, пользовательские эмодзи, текстовые и голосовые каналы, видеосвязь и демонстрацию экрана. Главная особенность проекта: анонимность и простой доступ через вход по ссылке VPN-подписки.

## Публичная демонстрация

Локальная демонстрация браузерного чата на React и TypeScript. В ней используются
компоненты и утилиты личного проекта WebChat.

Из исходного проекта взяты группировка каналов, форматирование вложений,
настройка клавиатурной отправки и индикатор набора. Для демонстрации они собраны
в отдельный интерфейс без подключения к исходному серверу.

## Возможности демонстрации

- Переключение каналов с независимыми списками сообщений.
- Отправка сообщений по Enter или Ctrl / Cmd + Enter.
- Сохранение выбранного режима отправки в браузере.
- Демонстрационный индикатор набора.
- Адаптивный интерфейс и тесты компонентов.

Сообщения хранятся в памяти вкладки и удаляются при обновлении страницы. Участники, каналы и исходные сообщения вымышлены.
Сообщения отправляются внутри локальной демонстрации. Обмена между пользователями
и соединения WebSocket в публичной версии нет.

Не включены авторизация, серверные интеграции, голосовые сервисы, push-ключи,
инфраструктура развёртывания, исходные переменные окружения, отчёты аудита,
реальные аккаунты, диалоги и бинарные материалы. История исходного проекта
не переносилась. Опубликована только локальная демонстрация.
