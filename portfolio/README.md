# Portfolio web

Версия интерфейса портфолио без личных сведений, контактов, работодателей, резюме
и оригинальных изображений. Графика карточки генерируется кодом.

Сохранены два языка интерфейса, интерактивная сетка навыков, модальные окна,
WebGL-анимации и поддержка `prefers-reduced-motion`.

Демонстрация не содержит аналитических трекеров, внешних рабочих API, формы
отправки данных или PDF с резюме. Описания навыков показывают содержание
интерфейса. Сведения о конкретных работодателях и результатах исключены.
