# Portfolio web

Обезличенная версия интерфейса портфолио. Личные сведения, контакты, работодатели,
резюме и оригинальные изображения исключены. Карточка использует процедурную графику.

Сохранены двуязычный интерфейс, интерактивная сетка навыков, модальные окна,
WebGL-анимации и поддержка `prefers-reduced-motion`.

```sh
cd portfolio
npm ci
npm run dev
```

Для проверки:

```sh
npm run lint
npm run build
```

Демонстрация не содержит аналитических трекеров, внешних рабочих API, формы
отправки данных или PDF с резюме. Описания навыков демонстрируют содержимое
интерфейса; сведения о конкретных работодателях и результатах здесь отсутствуют.
