# Support toolkit

Независимые функции, выделенные из API для инструментов поддержки. В публичную
версию не включены бизнес-правила, интеграции, база данных и клиентские записи.

- `email.ts`: нормализация email для безопасного использования в сегменте пути.
- `validate.ts`: проверка формы тела запроса, строковых полей и UUID.
- `password.ts`: scrypt, случайная соль, самоописательный формат хеша и сравнение
  результата через `timingSafeEqual`.

```sh
node --test project-2/toolkit.test.mjs
```

Команда запускается из корня репозитория на Node.js 24+.
Тестовые строки паролей вымышлены и существуют только для проверки алгоритма.
Это набор функций, а не готовая система аутентификации: HTTP-слой, ограничение
попыток входа и управление сессиями сюда не входят.
